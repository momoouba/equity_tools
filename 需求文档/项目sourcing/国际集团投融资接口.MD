投融资查询接口
接口说明
上海国际企业数据总线系统的投融资查询接口实现了通过标准接口查询上海国际集团外部融合平台投融资数据的功能。
接口服务说明
接口地址：
生产环境：
[内网] 
[外网] 
测试环境：
[内网]
http://test_esb.sigchina.com:8000/dofp/v2/ipaas/query/dealDetailInfer 
[外网] 
接口说明：使用地址时需要添加Header头信息，请求方式为POST，正文格式为application/json; charset=UTF-8。
参数名	示例	类型	是否必填	说明
X-App-Id		String	是	Ipass平台授权的消费方标识，固定值
X-Sequence-No	ca007b5a-35df-422c-939d-13f9a08eb69b	String	是	消息流水号：自定义uuid
X-Timestamp	1741089263217	String	是	时间戳
APIkey		String	是	消费方认证，固定值
请求报文格式
根据编码查询：
其他系统查询上海国际企业数据总线系统的投融资查询接口的报文格式：
表  查询接口请求报文格式
{
    "query_type": "queryByCode",
    "instn_idtfn_cd": "91110112MA007WE796"
}
字段说明如下表所示：
表  字段说明
属性	名称	数据类型	是否必填	说明
query_type	查询方式	String	是	queryByCode：根据编码查询
queryByDate：根据融资日期查询
fuzzyQuery：根据投资方模糊查询
instn_idtfn_cd	被投机构唯一识别码	String	是	
根据融资日期查询：
其他系统查询上海国际企业数据总线系统的投融资查询接口的报文格式：
表  查询接口请求报文格式
{
   "query_type":"queryByDate",
   "funding_dt":"2025-10-21"
}
字段说明如下表所示：
表  字段说明
属性	名称	数据类型	是否必填	说明
query_type	查询方式	String	是	queryByCode：根据编码查询
queryByDate：根据融资日期查询
fuzzyQuery：根据投资方名称模糊查询
funding_dt	融资日期	String	是	格式：yyyy-MM-dd
根据投资方名称模糊查询：
其他系统查询上海国际企业数据总线系统的投融资查询接口的报文格式：
表  查询接口请求报文格式
{
    "query_type": "fuzzyQuery",
    "inv_nm": "CMC",
    "start_time": "2017-03-22",
    "end_time": "2017-03-22"
}
字段说明如下表所示：
表  字段说明
属性	名称	数据类型	是否必填	说明
query_type	查询方式	String	是	queryByCode：根据编码查询
queryByDate：根据融资日期查询
fuzzyQuery：根据投资方模糊查询
inv_nm	投资方名称	String	是	投资方名称，输入内容长度大于等于3
start_time	投资时间范围开始时间	String	是	日期格式：yyyy-MM-dd
end_time	投资时间范围结束时间	String	是	日期格式：yyyy-MM-dd
