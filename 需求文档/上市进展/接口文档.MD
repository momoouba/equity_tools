## 2. 约定

- **Base URL**：`/api/listing`
- **鉴权**：沿用系统登录态与菜单权限（需具备“上市进展”权限）
- **时区**：所有日期口径均为 `Asia/Shanghai`
- **通用成功返回**：

```json
{
  "success": true,
  "message": "ok",
  "data": {}
}
```

- **通用失败返回**：

```json
{
  "success": false,
  "message": "error message",
  "code": "BUSINESS_ERROR"
}
```

## 3. 打新日历（2026-04-13、2026-04-14）

对应需求：`14.1`、`14.1.1`、`15.5`

### 3.1 查询打新日历列表

- **Method**：`GET`
- **Path**：`/new-share`

#### Query 参数

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| page | number | 否 | 页码，默认 1 |
| pageSize | number | 否 | 每页条数，默认 20 |
| startDate | string(date) | 否 | 申购日期起（含） |
| endDate | string(date) | 否 | 申购日期止（含） |
| keyword | string | 否 | 股票代码/股票简称模糊搜索 |
| exchange | string | 否 | 交易所（上交所/深交所/北交所/港交所） |

#### 返回 data

| 字段 | 类型 | 说明 |
|---|---|---|
| list | array | 列表数据 |
| total | number | 总条数 |

`list[]` 字段建议：
`stock_code`、`stock_name`、`issue_date`、`issue_weekday`、`issue_price`、`limit_shares`、`total_issued_shares`、`public_date`、`win_rate`、`first_day_close`、`first_day_chg_pct`、`first_day_market_cap`、`enterprise_full_name_cn`、`enterprise_full_name_en`、`enterprise_full_name_display`、`exchange`、`updated_at`

- **`limit_shares`（港股 · 经济通 `listingipos`）**：入库值为 **顶头槌手数（`maxlotsize`）× 每手股数（`boardlot`）**，单位为 **股**，与港股频道「招股中」表口径一致；非经济通源或字段不可算时可能为空。
- **`enterprise_full_name_display`（新增-2026-04-22）**：用于前端展示中英文企业全称；列表需单行展示，超出省略，悬停可见完整内容（前端 UI 约束）。

---

### 3.2 手动同步打新日历

- **Method**：`POST`
- **Path**：`/new-share/sync`

#### Body 参数

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| from | string(date) | 否 | 手动同步开始日期 |
| to | string(date) | 否 | 手动同步结束日期 |
| force | boolean | 否 | 是否强制刷新，默认 false |

#### 说明

- 按 `stock_code` 去重（必要时实现可加 `exchange` 联合）
- 未补全记录需持续补抓直到补全完成
- 北交所中签率 `win_rate` 不写入
- 港交所来源：仅抓取“相关企业活动=新上市”
- 定时任务每日对港交所数据补抓最近一周窗口（用于晚更新补数）
- 上市后每日补抓首日指标（若原空值被更新）：
  - `first_day_close`（上市首日收盘价）
  - `first_day_chg_pct`（首日涨幅，数值类型，展示层转百分比）
  - `first_day_market_cap`（市值 = `first_day_close * total_issued_shares`）
- **新增-2026-04-22**：同步完成后对 `enterprise_full_name_display` 为空的数据执行 AI 补齐：
  - 输入：`stock_code` + `stock_name`
  - 输出：`enterprise_full_name_cn`、`enterprise_full_name_en`、`enterprise_full_name_display`
  - 模型：走系统“AI模型配置管理”生效配置
  - 提示词：优先“模型提示词设置”配置，缺失时走代码兜底提示词
  - 邮件逻辑：保持不变（不新增、不改顺序、不改字段）

---

### 3.3 导出打新日历

- **Method**：`GET`
- **Path**：`/new-share/export`
- **规则**：导出当前筛选结果；导出保留空单元格（展示层才显示 `-`）

## 5. 境外上市备案审核（2026-04-15、2026-04-20）

对应需求：`14.4`、`15.8`、`16.2`；**备案通知书列表 + 详情 HTML**：`14.5`、`15.8.1`、`16.3`（**`【证监会政府信息公开·备案通知书列表抓取 · 新增 · 2026-04-20】`**）

### 5.0 备案通知书列表抓取（业务说明，接口与同步入口对齐）

- **列表入口 URL**（政府信息公开 · 境外证券发行）：`http://www.csrc.gov.cn/csrc/c101935/zfxxgk_zdgk.shtml?channelid=8f3f0d4be56b4f8aa8183b3234b88ede`
- **数据落库**：`ipo_progress`，`board=境外发行备案`；标题筛选 **备案通知书**；详情页解析 **文号、发文日期、企业全称、上市交易所（正文「一、」段）** 等，字段映射见需求 **15.8.1**。
- **与 Excel 行合并**：同企业、**发文日期与 Excel 接收日期同一自然日** 时 **UPDATE** 为一条，`status=备案完成`，**`register_address` 以文号覆盖**原申报类型；企业匹配为 **规范化后全等**。
- **判重**：`board` + `project_name` + `register_address`（**文号**）。
- **定时**：与 **Excel 境外备案抓取同一执行时刻/同一任务批次**（实现须在日志中区分来源：`excel` / `notice_html`）。
- **手动同步时间窗**：`from`、`to` 闭区间 **跨度不得超过 30 天**，超出由接口返回业务错误（与需求一致）。
- **重试**：单次请求/页面失败 **最多 5 次**，**仅失败时重试**。

## 9. 同步日志接口

### 10.1 查询同步执行日志

- **Method**：`GET`
- **Path**：`/listing-sync-execution-log`

#### Query 参数

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| page | number | 否 | 页码，默认1 |
| pageSize | number | 否 | 每页，默认20 |
| sourceType | string | 否 | 来源类型过滤 |
| status | string | 否 | 状态过滤（running/success/failed/skipped） |
