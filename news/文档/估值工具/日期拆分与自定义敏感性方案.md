# 日期拆分与自定义敏感性

> 入口：项目估值工作台 → **方法配置** / **结果对比 · 敏感性**。  
> 股权价值、FCFF、残段现金流仍以 [DCF-锚定日折现与预测资产负债表方案](./DCF-锚定日折现与预测资产负债表方案.md) 为准，**本文改写其中「单一估值锚定日」与折现期公式**；敏感性结果区结构仍以 [敏感性分析-结果对比与退出收益方案](./敏感性分析-结果对比与退出收益方案.md) 为准，**本文在其四组预设之上增加单变量与自定义**。  
> 实现以本文为准。确认后按文末附录落地。

## 1. 要解决什么

1. **日期职责混在一起。** 现状 `assumptions.valuation_date`（界面「估值日」）同时当折现原点，并用「≤ 该日的最近季末」推导可比财报/倍数截止；标的当期三表实际列也跟这一天的年月走。投资日通常晚于最近报表日，需要能分开填，又不能让折现原点早于报表日。
2. **市场倍数缺「最新参考」。** 计算用倍数仍要有截取日；分析人员还要看到数据源最新可用交易日的 P/E、P/S（只读，不进结论），并标明取值日。
3. **敏感性轴不够。** 现有四组预设保留；需要单变量试算，以及自定义横轴/纵轴（步长或手填相对 Δ 档位）。

## 2. 三个日期（对照）

| 名称 | 字段（草案） | 可选范围 | 用途 |
|------|--------------|----------|------|
| 标的财务锚定日 | `assumptions.financial_anchor_date` | 任意日历日（常见各月月末） | 标的利润表/现金流量表/资产负债表实际列截止日；净负债与营运资本取数日；锚定年残段 = 全年 − **该日**累计 |
| DCF 折现基准日 | `assumptions.discount_base_date`（可由现 `valuation_date` 迁入或并存，见附录） | 任意日历日，且 **≥ 财务锚定日** | 全部 FCFF 与终值的折现原点；**计算用**可比 P/E、P/S 截取上限（该日及以前） |
| 最新交易日（展示） | 不入库为假设；计算/采集时写入可比行或结果旁路字段 | 各公司数据源最新可用交易日 | **只读参考**倍数与取值日；不进市场法区间、不进 DCF |

可比上市公司公开报表：按「≤ 折现基准日的最近季末」取报告期；界面「可比财报截止」只读展示该季末。标的自身三表仍跟财务锚定日。

### 2.1 联动与校验

- 新建或首次填财务锚定日：折现基准日默认 = 财务锚定日。
- **dirty 标记** `discount_base_dirty`（或等价：折现基准日曾被用户改过）：未脏则财务锚定日变更时折现基准日跟随；已脏则不跟随。
- 折现基准日 **不得早于** 财务锚定日。若改财务锚定日导致已脏的折现基准日变早： **自动抬升到等于新财务锚定日，并提示一句**。
- 财务锚定日未填或非法：市场法与 DCF 都不算（与现拦截一致，文案改为「标的财务锚定日」）。
- 折现基准日未填：回退为财务锚定日（若财务锚定日有效）；两者皆无则拦截。

### 2.2 折现（年末折现法）

- 每年 FCFF、终值仍落在该年 `12-31`。
- **不用**年中惯例。
- 期数改为实际天数 / 365：

```text
期数 = (该年 12-31 − 折现基准日) 的日历天数 / 365
折现因子 = 1 / (1 + 折现率) ^ 期数
```

例：折现基准日 `2026-11-01`，则 2026-12-31 的期数 ≈ 60/365 ≈ 0.164 年（约两个月量级；若基准落在 11 月中下旬则接近一个月）。

- 锚定年残段金额规则不变，但切分时点改为 **财务锚定日**（不是折现基准日）：期间税前/折旧/资本开支 = 年底全年 − 财务锚定日累计；ESOP 按财务锚定月剩余比例。接受「财务锚定日 → 折现基准日」之间已实现经营现金流仍进残段带来的轻微高估。
- 终值与最后一列预测年末使用同一期数；持有年数（退出 IRR）仍取最后一列折现期数。
- **预测年末 ≤ 折现基准日**（投资日跨过了该年年末）：该年 FCFF 期数按 **0**（现值=名义值，不向前复利）；若终值挂在该年，终值同样期数 0。结果区提示「折现基准日已不早于部分预测年末，这些年按期数 0 计入」。不删列、不拦截（常见于折现基准日略晚于财务锚定日且仍在首年年末之前；跨到下一年属于少见但允许）。

### 2.3 市场倍数

| 用途 | 截取规则 | 是否进结论 |
|------|----------|------------|
| 市场法区间 / 入池统计用的计算倍数 | `trade_date ≤ 折现基准日` | 是 |
| 最新交易日参考 P/E、P/S | 各公司数据源最新可用截面 | 否，只展示 |

展示（建议 **A**）：

- 可比公司表 **每行**：最新 P/E、P/S + 该行取值日。
- 汇总中位/平均旁：样本取值日范围（最早–最晚，或「共 N 个交易日」）。

改财务锚定日或可比名单仍触发重新采集（沿用敏感性文 5.4）；**仅改折现基准日**时：倍数截取上限变了，按「需要重新计算」处理；若库内已有足够历史截面可只重算不抓取，否则与现「锚定日变更重新采集」对齐——**折现基准日变更视同需按新截取日重算市场法**；若缺截面则采集。

## 3. 敏感性：预设 + 单变量 + 自定义

### 3.1 入口

结果对比右侧敏感性控件：

1. **四组预设**（保持现文第 6 节）：营收 CAGR×退出倍数、折现率×退出倍数、研发费用 CAGR×退出倍数、营收 CAGR×研发费用 CAGR。
2. **单变量试算**（与二维并列，不强制先做单变量）。
3. **自定义**（二维：自选横轴、纵轴）。

并购/上市共用轴与步长配置；输出仍为 **估值 / 退出 MOC / 退出 IRR** 三块；无退出倍数轴时仍左右并排 P/E、P/S（退出倍数固定为当前基准）。

### 3.2 可选参数（自定义与单变量）

| 轴 | 冲击方式 |
|----|----------|
| 营收 CAGR | 同现：第一年收入不变，其后按该档 CAGR 重铺 |
| 研发费用 CAGR | 同现 |
| 折现率 | 同现；&lt;1% 托底 |
| 退出倍数 | 同现：P/E 表扫退出 P/E，P/S 表扫退出 P/S（一个轴名，不是二选一） |
| 毛利率 | 对 **营业成本率** 做反向相对平移（毛利率 Δ=+2pct ⇒ 各年成本率 −2pct） |
| 销售费用率 / 管理费用率 / 研发费用率 | 各年该占收入比例 +Δ；**绝对额年份（\|格\|&gt;10000 当元）跳过，保持绝对额**，表下注明 |
| 资本开支占收入 | 同上；绝对额年份跳过 |
| DSO / 存货周转天数 / DPO | 各预测年天数 +Δ（天） |

水平类（费率、天数、资本开支率）一律 **相对当前预测路径平移**，不是拍成同一绝对水平。  
手填档位只填 **相对 Δ**（0 = 当前预测）。

### 3.3 步长与档位

- **步长模式**：对称五档，中心±2 步（与现预设相同）。
- **档位模式**：手填 3–7 个相对 Δ；若缺少 0（基准），**自动插入 0 并标为当前**。
- 单变量：一根轴，同一套步长/档位规则；一维表 × 两套退出。
- 二维自定义：横轴 ≠ 纵轴；同一参数禁止同时占两轴。
- 改轴/步长/档位后仍出第 5.4 节过期警告，点「开始采集/计算/保存」重算。

### 3.4 存储（methodConfig 草案）

```text
sensitivity_mode: preset | univariate | custom
sensitivity_axes: 现有四组枚举之一（preset 时）
sensitivity_row_param / sensitivity_col_param: 自定义或单变量的参数 id（单变量只用 row）
sensitivity_row_mode / sensitivity_col_mode: step | levels
sensitivity_*_step: 各参数步长（沿用 pe/ps/cagr/rd/rate，并增补 margin/opex/capex/dso/dio/dpo 等）
sensitivity_*_levels: 相对 Δ 数组（档位模式）
```

导入模板：预设 1–4 保持；自定义/单变量以页面配置为准，模板可不强制覆盖（空着不覆盖，与现敏感性三行一致）。若加行，另开一小表或说明页，本文不阻塞开发。

## 4. 与旧文冲突时以谁为准

| 旧约定 | 本文 |
|--------|------|
| DCF 文「不新增第二套锚定日」「市场法与折现原点共用」 | **废止**；拆成财务锚定日 + 折现基准日 |
| DCF 文折现期 = 整月差/12，原点=估值锚定日 | 原点=折现基准日；期数=实际天数/365 |
| 现状代码：单一 `valuation_date` + `reportCutoffYmd` 推导季末 | 财务锚定日任意日历日；折现基准日独立；计算倍数截取=折现基准日 |
| 敏感性文仅四组预设 | 保留四组，加单变量与自定义 |

## 5. 不做

- 不把最新交易日倍数写入市场法低高端或 DCF。
- 不允许折现基准日早于财务锚定日。
- 不恢复「敏感性内圈四角」作 DCF 区间。
- 自定义不把税金及附加率、其他收益率等未列参数默认开放（可后续加）。
- 不改退出 MOC/IRR 公式与投前估值/稀释即时重算规则。

## 6. 验收要点

1. 财务锚定日 `2026-09-30`、折现基准日 `2026-11-15`：残段按 9/30 切；2026E 折现期 = (2026-12-31−2026-11-15)/365；净负债取 9/30。
2. 折现基准日改早于财务锚定日：无法保存为非法态；改财务锚定日导致冲突时自动抬升并提示。
3. 未手改折现基准日时改财务锚定日：二者保持相等。
4. 市场法计算截面 `trade_date ≤ 折现基准日`；名单上另有最新倍数+日期，改最新日不影响未重算的区间条。
5. 预设四组行为与现网一致；自定义「毛利率 × 折现率」出三块×双退出；单变量「销售费用率」出一维三块。
6. 某年销售费用为绝对额时，扫销售费用率该年不变，表下有说明。
