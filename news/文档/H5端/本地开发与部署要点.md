# H5 本地开发与部署要点（一期）

## 本地开发

```bash
# 终端1：后端
cd news && npm run server

# 终端2：PC（含同址跳转探针）
cd news && npm run client
# → http://localhost:5173

# 终端3：H5
cd news && npm run client-h5
# → http://localhost:5174/h5/
```

- 手机 UA / DevTools 设备模式打开 `http://localhost:5173/login` → 跳到 `http://localhost:5174/h5/login`（`VITE_H5_DEV_ORIGIN` 可改）。
- 强制电脑版：`?pc=1` 或 `localStorage.force_pc=1`。
- 会话键与 PC 相同（`user` / `auth_remember_me`），同浏览器下登录态可共用。

## 生产构建

```bash
cd news/client-h5 && npm run build
# 产物 dist/，部署到 Nginx 静态根下的 h5/ 目录，使
#   /h5/index.html、/h5/assets/* 可访问
```

`nginx-docker.conf` 已增加 `location /h5/`。若生产用 volume 只同步 PC `client/dist`，需额外把 `client-h5/dist` 拷到同一 html 根的 `h5/` 子目录。
