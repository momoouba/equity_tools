# H5 一期 · 页面与接口清单

> 依据 [H5接入方案.md](./H5接入方案.md) **v0.5 已确认范围**。  
> 状态：清单已出 · **一期研发进行中**（`news/client-h5` 已脚手架）

---

## 1. 范围摘要

| 项 | 内容 |
|----|------|
| 入口 | 同址；手机自动进 H5（§1.1） |
| 页面 | 登录、首页壳、舆情列表、舆情详情、我的（退出） |
| 数据口径 | **仅**「我的企业相关」（`/api/news/user-news`）；管理员手机端同样 |
| 不做 | 写操作、配置、分享页、免登、打新（二期）、全量管理员舆情 |

---

## 2. 页面

| 路由（对内） | 说明 |
|--------------|------|
| `/h5/login` | 账号密码；复用 PC 登录 API |
| `/h5/` | 首页；有舆情权限则入口卡片 |
| `/h5/news` | 列表：时间范围 + 关键词；卡片流 |
| `/h5/news/:id` | 详情：摘要/情绪/类型/企业/原文链（只读打开） |
| `/h5/me` | 用户信息摘要 + 退出 |

PC：`/login`、`/` 等手机访问 → 跳转到上表对应页（排除分享路径）。

---

## 3. 接口白名单（一期）

| 方法 | 路径 | 用途 |
|------|------|------|
| POST | `/api/auth/login` | 登录 |
| GET | 现有用户/权限接口（与 PC 登录后一致，以实现为准） | 拉 `app_permissions` |
| GET | `/api/news/user-news` | 舆情列表；H5 另传 `h5Category`：`all` / `enterprise` / `半导体` / `生物医疗` / `人工智能` / `其他`（企业=被投企业；行业=第三方公众号 industry_tag） |
| GET | `/api/news/user-stats` | 可选；有则首页/列表顶统计 |
| GET | 详情：优先复用现有单条查询；若无合适 GET 再补 `/api/h5/news/:id` 只读 | 详情字段瘦身可二选一 |

**禁止调用（示例）**：`/api/news/export`、分析重跑、`/api/news-share/*` 管理端、专队/wewe、一切 POST/PUT/DELETE 业务写接口。

---

## 4. 验收

1. 手机打开与 PC 相同网址 → 进入 H5 登录/首页。  
2. 电脑打开 → 仍为 PC。  
3. `/share/...` → 不进 H5 壳。  
4. 登录后仅能浏览本人企业相关舆情列表与详情；无写按钮。  
5. 管理员账号在 H5 上亦为「我的企业」口径，而非 PC 全量管理台。
