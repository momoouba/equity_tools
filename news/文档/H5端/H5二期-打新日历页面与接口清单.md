# H5 二期 · 打新日历（只读）清单

> 依据 [H5接入方案.md](./H5接入方案.md) 阶段 2a。本地先跑通，再生产。

## 范围

| 做 | 不做 |
|----|------|
| Tab：**已上市** / **未上市**；列表 + 详情 | 同步 / AI 查名 / 导出 |
| 已上市：卡片含首日涨幅、市值；按 **上市日** 排序分组 | 勾选、写操作 |
| 未上市：卡片不含上述两字段；按 **申购日** 排序分组 | |
| 交易所筛选 + 代码/简称搜索（可折叠） | |
| 首页入口 + 底栏「打新」（有上市进展权限时） | 分享页 |

## 路由

| 路径 | 说明 |
|------|------|
| `/h5/listing/new-share` | 列表 |
| `/h5/listing/new-share/:id` | 详情 |

## 接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/listing/new-share` | 复用现网列表；H5 传 `listedStatus=listed\|unlisted`（已上市按 `public_date`，未上市按 `issue_date`） |
| GET | `/api/h5/listing/new-share/:id` | H5 详情只读 |

权限：后端 `LISTING_FEATURE.NEW_SHARE`（非 admin 通常需 VIP）；前端入口按「上市进展」应用权限显隐，无 feature 时列表页提示。

## 验收

1. 有权限账号可在 H5 浏览打新列表、点进详情。  
2. 无写按钮；403 时有明确提示。  
3. 不影响 PC 打新页。
