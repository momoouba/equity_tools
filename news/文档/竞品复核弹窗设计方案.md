# 竞品复核弹窗设计方案

> 实现入口：`CompetitorRelationReviewDrawer.jsx`。

## 目标

1. 右侧 Drawer → 居中 Modal（约 1040px，尽量一屏）
2. 展示证据四维与匹配综合分的计算依据
3. 复核表单逻辑不变

## 依据数据从哪来

| 来源 | 说明 |
|------|------|
| **跑批落库（优先）** | `evidence_breakdown_json.dimension_reasons` / `calc_detail_lines` / `consistency_detail` 等；`score_breakdown_json.score_reason_lines` / `score_formula` |
| **刷新证据** | 重算并写回 `evidence_breakdown_json`（含新依据） |
| **前端兜底** | 旧数据无上述字段时，按分数反推 |

生成位置：`buildEvidenceMeta`（证据）、`describeComprehensiveScore`（综合分）→ `mapCandidateToPersistRow` 落库。无需新表。

## 历史数据

- 未重跑的关系：前端继续反推展示
- 要看到跑批时写死的依据（含重叠率、字数）：对该主体**重新跑竞品分析**
- 仅更新证据侧：点弹窗内**刷新证据**
